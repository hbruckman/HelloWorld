DESIGNED & BUILT WITH CODEX

Small app.
Full-stack thinking.

An interactive showcase, from the first pixel to the last API test.

01 / ENGINEERING

C# at the core.

ASP.NET Core minimal APIs power a deterministic, clock-driven simulation. Mission snapshots are independent of polling frequency, with bounded in-memory storage and validated inputs.

02 / EXPERIENCE

A view into the unknown.

A responsive, dependency-free interface with a procedural starfield, animated probe positions, live telemetry, session archives, and downloadable JSON reports.

03 / CONFIDENCE

Built to be checked.

xUnit tests exercise time progression, fleet boundaries, HTTP validation, and the real application pipeline. All observations are simulated; no external data or credentials are needed.
